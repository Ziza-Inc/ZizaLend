## Context

The codebase and documentation use remittance, score, loan, collateral, share, pool, ledger, term, stroop, SAC, and governance without defining them. A contributor from outside Stellar meets `stroop` and `ledger` and has to leave the repository to proceed, which is where contributors are lost.

## Task

- Define every domain and Stellar-specific term the project uses
- Keep each definition to a sentence, with a link for depth
- Reference the glossary from the README and the contributing guide

## Definition of Done

- Every term used in the README is defined
- The definitions match the contract semantics rather than the general meaning

- `docs/`
