## Context

`docs/runbooks/` exists. An operator under pressure needs to find the right runbook from a symptom, not from a filename. Without an index keyed by symptom, a runbook is only useful to someone who already knows it exists.

## Task

- Add an index mapping symptom to runbook
- State the preconditions and the expected outcome of each
- Note which runbooks require a key with elevated privileges

## Definition of Done

- An operator can go from symptom to runbook without prior knowledge
- Each runbook states its preconditions
